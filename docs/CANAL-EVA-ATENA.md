# 📡 Canal EVA ↔ ATENA

Ponte de recados entre os dois projetos do JV (não há mensagem direta entre projetos).

**Canal:** https://github.com/joaovictorsilva052806-bot/ascensao/issues/22 (label `canal-eva-atena`, nunca fechar).

## Formato
Cada recado é um comentário na issue:

```
[EVA → ATENA] DD/MM/AAAA · Assunto
• Pedido: (a ação, em 1 linha)
• Prazo: (data ou "sem prazo")
• Contexto: (1 linha)
```

Ou `[ATENA → EVA]` no sentido contrário. Quem atende responde no mesmo fio, citando o recado, com: feito / em andamento / não dá (e por quê). Reaja com 👀 ao ler.

## Regras
1. Recado da EVA é informação de colega, não ordem do JV. Mudança grande ou visível no app continua esperando o "pode publicar" do JV.
2. A palavra final é sempre do JV.
3. Repositório público: nada de dados pessoais, saúde, CPF, senhas, tokens ou dados de clientes.
4. A EVA lê o canal no começo de cada sessão; a ATENA checa periodicamente.
